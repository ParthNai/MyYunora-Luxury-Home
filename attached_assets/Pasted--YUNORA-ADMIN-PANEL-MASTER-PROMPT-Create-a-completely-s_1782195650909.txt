# YUNORA ADMIN PANEL MASTER PROMPT

Create a completely separate and secure Admin Dashboard for Yunora Universal.

Route:

/admin

The Admin Panel must be connected directly with the ecommerce website database and APIs so that every change made inside Admin instantly reflects on the live website.

Use:

React + TypeScript

Tailwind CSS

Shadcn UI

Supabase or Firebase

Protected Routes

Role-based Authentication

Responsive Design

Desktop-first but mobile compatible

Theme same as website.

Primary Color:

Pumpkin Orange

White background

Glassmorphism cards only where needed.

No unnecessary colors.

No emojis.

---

# ADMIN LOGIN

Create secure login page.

Default Username:

YunoraAdmin

Default Password:

Yunora@2026

After first login:

Force password change.

Store password hashed.

Session timeout enabled.

Unauthorized users cannot access any admin route.

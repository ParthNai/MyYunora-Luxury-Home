# SECURITY REQUIREMENTS

Audit logs.

Activity history.

Password hashing.

Session timeout.

Role based access control.

Protected APIs.

Input validation.

Rate limiting.

No unauthorized access.

Everything should be connected with the same database and same API architecture.

No hardcoded data.

All updates must reflect automatically across the website and admin panel.

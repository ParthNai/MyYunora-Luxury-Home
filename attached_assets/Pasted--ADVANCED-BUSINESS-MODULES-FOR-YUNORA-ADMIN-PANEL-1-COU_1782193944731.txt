# ADVANCED BUSINESS MODULES FOR YUNORA ADMIN PANEL

---

# 1. COUPON MANAGEMENT SYSTEM

Admin should be able to:

Create coupon codes

Edit coupon codes

Delete coupons

Enable/Disable coupons

Set:

Coupon Name

Coupon Code

Discount Percentage

Flat Discount

Minimum Order Value

Maximum Discount Amount

Expiry Date

Usage Limit

Single Use Per Customer

Applicable Categories

Applicable Products

Dashboard should show:

Active Coupons

Expired Coupons

Coupon Usage Count

Revenue Generated Through Coupons

All modules must use the same database as the website.

No hardcoded values.

Everything dynamic.

Every change should reflect automatically.

Use reusable APIs and clean architecture.

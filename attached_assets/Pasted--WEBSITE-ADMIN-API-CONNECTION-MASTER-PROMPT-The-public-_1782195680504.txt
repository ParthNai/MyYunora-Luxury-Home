# WEBSITE + ADMIN + API CONNECTION MASTER PROMPT

The public website and admin panel must be fully connected.

Do NOT create separate hardcoded systems.

Both website and admin panel must use:

* Same Database
* Same APIs
* Same Product Collections
* Same User Collections
* Same Settings Collections

Technology:

React + TypeScript

Supabase (preferred) or Firebase

REST APIs or Server Actions

Reusable architecture

Everything must be dynamic.

No hardcoded text.

---

# DATA FLOW

Admin → Database → Website

Whenever admin updates anything:

Changes should immediately appear on website.

No manual coding required.

No redeployment required.
